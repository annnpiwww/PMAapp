BSS TimeMark - Release Notes v2.0.17

Direct Share (WA/Telegram) Fixes - Grooming Absensi & Maintenance (ARM64 Optimized)

Apa yang Diperbaiki?

✓

Custom FileProvider Authority

Memisahkan FileProvider dari bawaan package share_plus dengan membuat authority custom (${applicationId}.direct_share_provider) di AndroidManifest. Mencegah bentrok dan limitasi akses native.

✓

Root Path Access (Bebas Path Restriction)

Menambahkan konfigurasi <root-path name="root" path="." /> di provider_paths.xml. Kini semua folder penyimpanan hasil jepretan kamera (app_flutter, external, cache) 100% punya otorisasi share ke aplikasi luar tanpa *throw IllegalArgumentException*.

✓

Extended Telegram Client Support

Dukungan untuk bypass system picker langsung ke aplikasi Mod/Fork Telegram (seperti Telegram X, Plus Messenger, Nekogram, Challegram) tanpa memicu error "Package Not Found".

✓

Single Image Intent Fix (Maintenance & Grooming)

Memperbaiki bug Kotlin di mana lampiran *single image* yang dipassing lewat array imagePaths salah terbaca sebagai `text/plain`. Sekarang fallback antara ACTION_SEND (single) dan ACTION_SEND_MULTIPLE (banyak file) beroperasi sempurna.

Catatan Keamanan Android 11+ (Work Profile & Dual Apps)
Jika HP yang digunakan mengisolasi WhatsApp/Telegram di dalam Secure Folder (Samsung) atau Work Profile, aplikasi di profil utama secara default diblokir oleh OS Android untuk mengirim *direct intent* ke dalam profil ganda tersebut. Dalam skenario OS strict seperti ini, lemparan ke dialog Share System Chooser adalah perilaku aman bawaan sistem, bukan bug aplikasi.
