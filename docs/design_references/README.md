# 🎨 UI/UX Design References (Exclusive for Tukang Design)

Direktori ini adalah tempat penyimpanan referensi visual, screenshot inspirasi, mockup, dan catatan desain yang disukai oleh Aan.

## 🔒 Scope Access (mandortukangv2)
- ✅ **Tukang Design (`ui`)**: **WAJIB MEMBACA** file di folder ini sebagai benchmark estetika, palet warna, ritme layout, tipografi, dan micro-motion.
- ❌ **Tukang Coder (`coder`)**: DILARANG membaca folder ini (hemat token context & di luar scope logika).
- ❌ **Tukang Security (`sec`)**: DILARANG membaca folder ini (di luar scope security & QA).
- 👑 **Mandor**: Jangan masukkan folder ini ke `allowed_files` (itu izin edit). `orca-bridge` otomatis menambahkan baris `REFS docs/design_references/` (read-only) di setiap handoff ke `ui`.

## 📁 Jenis File yang Bisa Ditaruh di Sini:
1. **Screenshots / Images**: `.png`, `.jpg`, `.webp` (contoh: screenshot UI Dribbble, Apple, linear.app, dsb).
2. **Notes / System**: `notes.md` atau `DESIGN_SYSTEM.md` (catatan palet hex, font family, border radius, shadow tokens).
3. **Mockup / Wireframes**: Komponen visual referensi.
